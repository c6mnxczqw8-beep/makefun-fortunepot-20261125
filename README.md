# Fortune in a Pot — entry

A program/v1 entry for the make.fun "Fortune in a Pot"
bounty. `main.py` writes one fortune to `/output/entry.txt`
(or to `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is
set).

The fortune:

> You will outlive three of your owner's resolutions, be watered with renewed commitment, and get the big window.

Endurance, devotion, and a promotion to the big window --
the full plant career arc in one fortune. See
`CANDIDATES.md` for the full draft list this winner was
picked from.
